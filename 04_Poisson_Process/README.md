# 🎲 Практическое задание 4 — Пуассоновский процесс

**Источник:** `lectures (4).pdf`, страницы 134–137.

**По умолчанию запускается задача 1.** Параметры: `λ = 5`, `n = 10`, `N = 10000`. Номер задачи выбирается строкой `TASK = 1` в начале `main.py`. За один запуск открывается только рисунок выбранного пункта.

## 📋 Условие

Сравнить три алгоритма моделирования моментов событий на `[0, 1]`:

1. Схема Бернулли: `n` ячеек, вероятность успеха `p = min(λ / n, 1)`, точка на правом конце успешной ячейки.
2. Число событий из распределения Пуассона с параметром `λ`, затем независимые равномерные положения точек и их сортировка.
3. Независимые показательные времена ожидания со средним `1 / λ`, накопленные до выхода за правую границу.

Для каждого способа собрать числа событий во всех `N` реализациях, **включая нули**, и внутренние расстояния между соседними точками. Не добавлять расстояния до границ и между разными реализациями.

Построить распределения числа событий и расстояний. Числа событий сопоставить с распределением Пуассона. Для расстояний использовать одинаковые границы интервалов и нормировку.

Провести два отдельных эксперимента:

- при `λ = 5`, `N = 10000` сравнить `n = 10` и `n = 200`;
- при `λ = 5`, `n = 10` сравнить `N = 100` и `N = 10000` на схеме Бернулли.

В ТЗ значения параметров предложены как пример. Здесь оставлены по два значения, чтобы показать увеличение `n` и `N` с минимальным количеством графиков.

В дополнительном исследовании, указанном в условии, сохранить все первые времена ожидания третьего алгоритма, включая значения больше `1`, и сравнить их распределение с плотностью `λ · exp(-λt)`.

## 📚 Как устроено решение

В папке находятся только `main.py` и README. В начале кода записано условие; этапы выделены разделителями, строки снабжены пояснениями.

- `bernoulli_process(lam, n, N)` возвращает массив из `N` чисел событий и массив внутренних расстояний.
- `uniform_process(lam, N)` возвращает такие же два массива для второго алгоритма.
- `waiting_realization(lam)` строит одну реализацию третьего алгоритма и возвращает моменты событий и первое ожидание.
- `waiting_process(lam, N)` возвращает числа событий, внутренние расстояния и первые времена ожидания.

`np.diff(points)` вычисляет только разности соседних точек одной реализации. Для пустого массива и одной точки результат пуст. После этого расстояния добавляются в общий список.

Для третьего алгоритма первая точка — `W1`, вторая — `W1 + W2`, третья — `W1 + W2 + W3` и так далее. Как только сумма превышает `1`, останавливаемся: все последующие суммы ещё больше, поскольку ожидания положительны. Вышедшая за границу точка не сохраняется.

## 📊 Объяснения и выводы по ТЗ

### Почему выполняются условия приближения Пуассона

При фиксированном `λ > 0` и увеличении `n` в итоге `p = λ / n`. Поэтому `p → 0`, `n → ∞`, а `np = λ`. Это условия сходимости числа успехов к распределению Пуассона с параметром `λ`.

### Откуда берётся множитель `1 / n`

Вероятность одного дискретного времени ожидания сравнивается с вероятностью попасть в узкий интервал непрерывного времени. Ширина шага сетки равна `1 / n`, а вероятность такого интервала приближённо равна плотности, умноженной на его ширину: `fλ(k / n) · (1 / n)`.

### Что меняется при увеличении n

Шаг сетки `1 / n` уменьшается, возможные положения событий становятся плотнее. Распределения числа событий и внутренних расстояний первого алгоритма приближаются к результатам второго и третьего. У двух последних сетки нет: они моделируют сам процесс Пуассона на отрезке.

При `λ = 5` и выбранных `n` число событий в схеме Бернулли имеет среднее `5`, но дисперсию `λ(1 - λ / n)`:

| `n` | Шаг сетки | Дисперсия числа событий |
|---:|---:|---:|
| 10 | 0.1 | 2.5 |
| 200 | 0.005 | 4.875 |

У распределения Пуассона с `λ = 5` и среднее, и дисперсия равны `5`. Поэтому при `n = 10` распределение Бернулли заметно уже, а при увеличении `n` различие уменьшается. Если `n ≤ λ`, вероятность успеха равна `1` и число событий вообще постоянно: оно равно `n`.

### Что меняется при увеличении N

Относительные частоты и нормированные гистограммы становятся устойчивее: случайные колебания обычно уменьшаются. Однако при фиксированном `n = 10` первый алгоритм по-прежнему имеет дисперсию числа событий `2.5` вместо `5` и расстояния на сетке с шагом `0.1`. Увеличение `N` точнее показывает распределение грубой схемы, но не устраняет её отличие от процесса Пуассона.

### Чем первые ожидания отличаются от внутренних расстояний

Все первые ожидания `W1` имеют показательное распределение с плотностью `λ · exp(-λt)`, `t ≥ 0`, и средним `1 / λ = 0.2`. Они сохраняются даже при `W1 > 1`, когда на отрезке нет событий.

Во внутренние расстояния попадают только промежутки, **оба конца которых находятся в `[0, 1]`**. Длинные промежутки реже помещаются в окно наблюдения, поэтому их распределение не совпадает в точности с показательным. Эти расстояния сравниваются между тремя алгоритмами; с показательной плотностью сравниваются отдельно первые ожидания.
