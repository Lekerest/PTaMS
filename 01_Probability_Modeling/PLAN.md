## 1. Оценка числа π методом Монте-Карло

### Идея метода

В единичном квадрате `[0, 1] × [0, 1]` рассматривается вписанный круг с центром `(0.5, 0.5)` и радиусом `0.5`.

Генерируются случайные точки с независимыми координатами `x` и `y`. Точка попадает в круг, если:

```text
(x - 0.5)² + (y - 0.5)² ≤ 0.25
```

Отношение площади круга к площади квадрата равно `π / 4`, поэтому:

```text
π ≈ 4 × hits / n
```

где `hits` — количество точек внутри круга, а `n` — общее количество точек.

После каждой новой точки вычисляется абсолютная ошибка:

```python
absolute_error = abs(pi_estimate - math.pi)
```

### Параметры эксперимента

| Параметр | Значение |
|---|---:|
| Количество точек | `100000` |
| Seed | `42` |
| Диапазоны `x` и `y` | `[0, 1]` |
| Центр круга | `(0.5, 0.5)` |
| Радиус круга | `0.5` |

Эти значения являются выбранными параметрами эксперимента, а не дополнительными требованиями задания.

## 2. Оценка вероятности перколяции

### Идея метода

Создаётся прямоугольное клеточное поле. Каждая клетка независимо от остальных является:

- проходимой с вероятностью `p`;
- непроходимой с вероятностью `1 - p`.

Необходимо определить, существует ли путь по открытым клеткам от верхней строки поля до нижней. Разрешены переходы вверх, вниз, влево и вправо. Диагональные переходы запрещены.

Для поиска пути используется алгоритм **BFS (поиск в ширину)**.

### Определение вероятности

Для каждого значения `p` проводится несколько независимых экспериментов:

1. Создаётся новое случайное поле.
2. Выполняется поиск пути сверху вниз.
3. Фиксируется наличие или отсутствие перколяции.

Если из `M` экспериментов путь существует в `K`, вероятность оценивается как:

```text
P ≈ K / M
```

### Параметры эксперимента

| Параметр | Значение |
|---|---:|
| Размер поля | `30 × 30` |
| Опытов для каждого `p` | `1000` |
| Seed | `42` |

Используемые значения вероятности открытия клетки:

```text
0; 0.1; 0.2; 0.3; 0.4; 0.45; 0.5; 0.525; 0.55; 0.575;
0.6; 0.625; 0.65; 0.675; 0.7; 0.75; 0.8; 0.9; 1
```

Размер поля остаётся одинаковым для всех значений `p`.
