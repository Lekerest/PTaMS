## 📋 ТЗ, выделенное из лекционного материала

### Часть 1. Вычисление числа π

**Источник: страницы 36–38.**

1. Сгенерировать множество равномерно распределённых точек внутри квадрата. Координаты каждой точки генерировать независимо.
2. Для каждой точки определить, попала ли она в круг, вписанный в квадрат.
3. Найти долю попаданий и по отношению площадей получить приближённое значение π.
4. Построить график зависимости **абсолютной ошибки** от количества использованных точек:

   ```python
   absolute_error = abs(pi_estimate - math.pi)
   ```

5. Для графика допускается накопительный пересчёт после каждой новой точки. Ошибка на отдельных шагах может увеличиваться.

### Часть 2. Вычисление вероятности перколяции

**Источник: страницы 38–39.**

1. Создать прямоугольное поле из одинаковых квадратных клеток.
2. Сделать каждую клетку проходимой с заданной вероятностью `p`, **независимо от остальных клеток**.
3. Разрешить переходы только между проходимыми клетками с общей стороной. **Диагональные переходы запрещены.**
4. Проверить существование пути из верхнего ряда в нижний. Начальная и конечная клетки могут быть любыми в соответствующих рядах.
5. Для каждого `p` провести множество опытов, **в каждом опыте генерировать новое поле**.
6. Оценить вероятность перколяции как долю полей, для которых существует такой путь.
7. Построить график зависимости вероятности перколяции от `p`.
8. Самостоятельно выбрать размеры поля, набор `p` и число опытов. **Размеры поля должны быть одинаковыми для всех точек графика.**

### Общее требование к воспроизводимости

**Источник: страница 37.** В каждой программе начальное состояние генератора задаётся **один раз до генерации случайных чисел**. В решениях используется отдельный генератор `random.Random(seed)`, который передаётся в функции моделирования. Повторного задания seed внутри циклов нет.

## 📚 Связь решения с лекциями

| Положение | Страницы | Применение в работе |
|---|---|---|
| Пространство исходов и событие | 3–6 | Для π исход — точка, событие — попадание в круг. Для перколяции исход — целое поле, событие — существование пути. |
| Геометрическая вероятность | 19–20 | При равномерном выборе точки вероятность попадания равна отношению площадей. Для вписанного круга это `π / 4`. |
| Независимость | 25–27 | Координаты точек и состояния клеток моделируются независимыми случайными выборами. |
| Частотная интерпретация | 36 | Вероятность оценивается отношением числа успехов к общему числу опытов. |
| Псевдослучайные числа и seed | 37 | Фиксированное начальное состояние позволяет воспроизвести эксперимент. |
| Метод Монте-Карло | 38 | Искомая величина оценивается по результатам случайных испытаний. |

**Основная формула частотной оценки:**

$$
\widehat{P}(A)=\frac{K}{N},
$$

где `K` — число опытов, в которых произошло событие `A`, а `N` — общее число опытов.

Для конечного числа опытов это приближённая оценка. Фиксация seed обеспечивает повторяемость, но сама по себе не повышает точность.

## ⚙️ Выбранные параметры

| Параметр | Часть 1: π | Часть 2: перколяция |
|---|---|---|
| Начальное состояние | `seed = 42` | `seed = 42` |
| Область моделирования | Квадрат `[0, 1] × [0, 1]` | Поле `30 × 30` |
| Объём моделирования | `100 000` точек | `1 000` новых полей для каждого `p` |
| Проверяемое событие | Попадание во вписанный круг | Существование пути сверху вниз |
| Оценка | `4 × K / N` | `K / N` |

Набор вероятностей проходимости:

```text
0, 0.1, 0.2, 0.3, 0.4, 0.45, 0.5, 0.525, 0.55, 0.575,
0.6, 0.625, 0.65, 0.675, 0.7, 0.75, 0.8, 0.9, 1
```

Набор охватывает весь диапазон `[0, 1]` и содержит больше точек в области изменения вероятности перколяции. Эти численные параметры выбраны для решения: лекция не устанавливает их значения и не требует заданной точности или оценки критического порога бесконечной решётки.

## 🚀 Запуск

Требуется **Python 3.10 или новее**. Единственная прямая внешняя зависимость — **Matplotlib**; моделирование использует стандартную библиотеку Python.

Команды выполняются из корня проекта `PTaMS`:

```bash
python -m pip install -r 01_Probability_Modeling/requirements.txt

python -X utf8 01_Probability_Modeling/01_Pi_Monte_Carlo/pi_monte_carlo.py
python -X utf8 01_Probability_Modeling/02_Percolation/percolation.py
```

По умолчанию программы сохраняют графики без открытия окон. Для просмотра окон добавьте `--show`:

```bash
python -X utf8 01_Probability_Modeling/01_Pi_Monte_Carlo/pi_monte_carlo.py --show
python -X utf8 01_Probability_Modeling/02_Percolation/percolation.py --show
```

Параметр `-X utf8` обеспечивает корректный вывод русского текста в терминале Windows. Команда `--help` выводит доступные параметры каждой программы. Повторный запуск обновляет файлы результатов соответствующей части; отчёты в README описывают запуск с параметрами по умолчанию.
