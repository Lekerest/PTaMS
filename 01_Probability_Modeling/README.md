# 🎲 Практическое задание 1 — Моделирование вероятности

**Источник:** `lectures.pdf`, страницы 36–39.

## 📋 Задание

1. Оценить число π по доле случайных точек, попавших в круг, вписанный в квадрат. Построить график абсолютной ошибки относительно `math.pi` в зависимости от числа точек.
2. Оценить вероятность существования пути от верхнего до нижнего ряда случайного клеточного поля. Построить график зависимости этой вероятности от вероятности проходимости клетки `p`.

В обеих программах seed задаётся один раз перед генерацией случайных чисел.

## 📁 Решения

- [Вычисление числа π](01_Pi_Monte_Carlo/README.md)
- [Вероятность перколяции](02_Percolation/README.md)

В каждой папке находятся README и один скрипт. Параметры эксперимента заданы в начале кода. Результаты выводятся в консоль, графики открываются в окне.

## 🚀 Запуск

Установить библиотеку для графиков:

```bash
python -m pip install matplotlib
```

Из корня проекта `PTaMS`:

```bash
python 01_Probability_Modeling/01_Pi_Monte_Carlo/pi_monte_carlo.py
python 01_Probability_Modeling/02_Percolation/percolation.py
```
