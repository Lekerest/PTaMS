# 🎲 Практическое задание 3 — Бутстрэп

## 📋 Условие

Для одной выборки независимых одинаково распределённых наблюдений методом бутстрэпа оценить приближённые 95%-е доверительные интервалы для:

- медианного абсолютного отклонения: `MAD = median(|Xi - median(X)|)`;
- выборочной дисперсии.

Сравнить интервалы и сделать выводы, учитывая разные единицы измерения статистик.

## 📚 Решение

Используется выборка из примера в задании: **10 000** значений экспоненциального распределения с `scale = 1`. Начальное состояние генератора — `seed = 42`.

1. Рассчитываем MAD и дисперсию исходной выборки.
2. Создаём **10 000** бутстрэп-выборок. Каждая содержит столько же элементов, сколько исходная, выбранных из неё **с возвращением**: одно наблюдение может попасть несколько раз, другое — ни разу.
3. Для каждой повторной выборки заново вычисляем её медиану, MAD и дисперсию. Обе статистики считаем по одной и той же повторной выборке.
4. Нижнюю и верхнюю границы каждого интервала получаем как процентили **2,5% и 97,5%** бутстрэп-значений соответствующей статистики.

MAD вычисляется по формуле условия, без дополнительных множителей. Выборочная дисперсия рассчитывается с делением на `n` (`ddof=0`); исправленная дисперсия с делением на `n - 1` здесь не используется.

## 📊 Результаты и вывод

| Статистика | Оценка по исходной выборке | Приближённый 95%-й интервал |
|---|---:|---|
| MAD | 0.468769 | [0.455388; 0.481495] |
| Выборочная дисперсия | 0.949370 | [0.899676; 1.000036] |

MAD имеет единицы исходных данных, дисперсия — квадрат этих единиц. Поэтому сравниваем **относительные ширины**:

```text
относительная ширина = (верхняя граница - нижняя граница) / исходная оценка
```

Относительная ширина интервала MAD составила **5,57%**, дисперсии — **10,57%**. В этом эксперименте неопределённость MAD относительно его оценки меньше. Напрямую сравнивать абсолютные ширины нельзя из-за разных единиц измерения.
