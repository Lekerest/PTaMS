## 📚 Задача 1. Генераторы

Пусть `U` и `V` — независимые равномерные числа. Для квантильного преобразования решаем уравнение `F(x) = U`.

**Два значения.** Если `U < p`, возвращаем +1, иначе −1. Длины частей `[0, p)` и `[p, 1)` равны нужным вероятностям.

**Показательное распределение.** При `x ≥ 0`:

```text
F(x) = ∫₀ˣ λ exp(−λt) dt = 1 − exp(−λx).
u = 1 − exp(−λx)  ⇒  exp(−λx) = 1 − u  ⇒  x = −ln(1−u)/λ.
```

При `x < 0` функция распределения равна 0.

**Нормальное распределение.** Используем преобразование Бокса–Мюллера:

```text
Z₁ = √(−2 ln U) cos(2πV),   Z₂ = √(−2 ln U) sin(2πV).
```

Обе величины стандартные нормальные. Для получения выборки достаточно брать `Z₁` из каждой независимой пары `U, V`.

**Парето.** Для заданной плотности `3/(2x^(5/2))`, при `x > 1`:

```text
F(x) = ∫₁ˣ 3/(2t^(5/2)) dt = 1 − x^(−3/2).
u = 1 − x^(−3/2)  ⇒  x^(−3/2) = 1 − u  ⇒  x = (1−u)^(−2/3).
```

При `x ≤ 1` функция распределения равна 0.

**Коши.** Для всех действительных `x`:

```text
F(x) = ∫₋∞ˣ 1/[π(1+t²)] dt = 1/2 + arctan(x)/π.
u = 1/2 + arctan(x)/π  ⇒  x = tan(π(u−1/2)).
```

**Графики:** пять панелей, по одной на каждый закон. Для ±1 высота синего столбца — относительная частота, красного контура — теоретическая вероятность. Для непрерывных законов высота равна `число наблюдений / (объём всей выборки × ширина интервала)`; красная линия — плотность.

Для Парето показано окно `[1, 10]`, для Коши — `[−10, 10]`. Значения вне окна остаются в знаменателе. Поэтому площадь показанной гистограммы равна доле всей выборки в окне, а не единице. С увеличением объёма выборки случайные отклонения частот обычно уменьшаются.

## 📚 Задача 2. Отбраковка

Плотность равна нулю вне `(0, 1)`. На этом интервале:

```text
∫₀¹ f(x) dx = (∫₀¹ 1 dx + ∫₀¹ x dx + ∫₀¹ sin²(3πx) dx) / 2
             = (1 + 1/2 + 1/2) / 2 = 1.
0 ≤ x ≤ 1 и 0 ≤ sin²(3πx) ≤ 1  ⇒  0 ≤ f(x) ≤ 3/2.
```

Получаем независимые координаты `U` и `V = 1.5 × uniform`. Если `V < f(U)`, сохраняем `U`. Повторяем до получения нужного количества значений.

Для малого интервала длины `dx` площадь принятой полосы равна `f(x) dx`. Вся принятая область имеет площадь 1, поэтому условная вероятность попадания сохранённого значения в эту полосу равна `f(x) dx`: это нужная плотность.

Теоретическая доля принятых точек — отношение площади под плотностью к площади прямоугольника: `1 / (1 × 1.5) = 2/3`. Фактическая доля выводится в консоль по **всем** попыткам.

**Графики:** слева плотность и первые 400 пробных точек двух цветов; справа гистограмма всей принятой выборки и плотность. Доля принятия должна быть близка к `2/3`, гистограмма — повторять форму плотности.

## 📚 Задача 3. Случайные блуждания

Каждая траектория начинается в нуле: `S₀ = 0`. Затем `Sₖ = ξ₁ + … + ξₖ`. Для разных траекторий генерируются независимые последовательности шагов.

| Закон шага | μ = E[ξ] | σ² = D[ξ] |
|---|---:|---:|
| ±1, p = 0.5 | 0 | 1 |
| ±1, p = 0.55 | 0.1 | 0.99 |
| Показательный, λ = 1 | 1 | 1 |
| Стандартный нормальный | 0 | 1 |
| Плотность задачи 2 | 13/24 ≈ 0.541667 | 47/576 − 1/(72π²) ≈ 0.080190 |

Для ±1: `μ = p − (1−p) = 2p−1`, `E[ξ²] = 1`, поэтому `σ² = 1 − (2p−1)²`. Для показательного: `μ = 1/λ`, `σ² = 1/λ²`.

Для плотности задачи 2 используем `sin²(3πx) = (1−cos(6πx))/2`:

```text
f(x) = 3/4 + x/2 − cos(6πx)/4,   0 < x < 1.
μ = ∫₀¹ x f(x) dx = 3/8 + 1/6 = 13/24.
E[ξ²] = ∫₀¹ x² f(x) dx = 1/4 + 1/8 − 1/(72π²).
σ² = E[ξ²] − μ² = 47/576 − 1/(72π²).
```

При независимых шагах с конечной дисперсией:

```text
E[Sₖ] = kμ,   D[Sₖ] = kσ²,   std(Sₖ) = σ√k.
```

**Первый рисунок:** по три траектории каждого из пяти законов и отдельная панель центрированных показательных шагов. По горизонтали — число шагов, по вертикали — положение. Красная линия — среднее по всем `N` траекториям, чёрный пунктир — `kμ`. У симметричных ±1 и нормальных шагов нет среднего дрейфа; у остальных перечисленных законов среднее положение растёт.

**Второй рисунок:** для каждого закона стандартное отклонение по всем `N` положениям в один момент времени и теоретическая кривая `σ√k` того же цвета, пунктиром. Разброс между траекториями растёт как корень из числа шагов. Это не стандартное отклонение точек вдоль одной траектории.

**Центрирование показательных шагов:** используются те же значения `ξ`, меняется только шаг на `ξ−1`. Поэтому новая траектория равна `Sₖ−k`, её среднее равно нулю. Вычитание одной константы из всех положений в момент `k` не меняет разброс; выборочные стандартные отклонения исходного и центрированного блужданий совпадают.

**Числовое сравнение:** программа выводит теоретические и выборочные средние и стандартные отклонения при `n = 100` и `n = 10000` для каждого закона. Используются положения тех же `N` траекторий в двух моментах времени. При увеличении числа шагов в 100 раз теоретическое среднее умножается на 100, стандартное отклонение — на 10. Нулевое теоретическое среднее остаётся нулём. Случайные выборочные значения могут отличаться от теоретических.

## 📚 Задача 4. Центральная предельная теорема

Для каждой из `N` независимых последовательностей шагов вычисляем:

```text
η = (Sₙ − nμ) / (σ√n).
```

Используем теоретические `μ` и `σ²` плотности задачи 2 из предыдущего раздела. ЦПТ утверждает приближение закона этой величины к стандартному нормальному при увеличении `n`.

**Графики:** первые четыре панели — `n = 1, 2, 10, 100` при одном `N`; пятая — сравнение `N` и `10N` при фиксированном `n = 10`; шестая — стандартные нормальные шаги при `n = 1`. Во всех панелях одинаковые интервалы гистограмм и масштабы осей. Красная линия — стандартная нормальная плотность.

**Вывод:** увеличение `n` меняет закон стандартизованной суммы, приближая его к нормальному. Увеличение `N` уменьшает случайные колебания гистограммы, точнее показывая тот же закон. Из-за случайности гистограммы не обязаны становиться ближе к нормальной при каждом увеличении `n`. Для нормальных шагов стандартизованная сумма имеет нормальный закон точно при любом `n`, включая `n = 1`.

## 📚 Задача 5. Тяжёлые хвосты

**Графики:** слева по одной траектории пяти законов из задачи 3 для сравнения; в центре три траектории Парето; справа три траектории Коши. На всех панелях одинаковое число шагов `n`. Масштабы вертикальных осей подстраиваются под положения соответствующих блужданий.

**Парето:** все шаги положительны, возможны редкие большие скачки вверх. Для заданной плотности:

```text
E[ξ] = (3/2) ∫₁∞ x^(−3/2) dx = 3.
E[ξ²] = (3/2) ∫₁∞ x^(−1/2) dx = ∞.
```

Поэтому `E[Sₖ] = 3k` применимо; при `k ≥ 1` дисперсия бесконечна. Формула конечного разброса `σ√k` и обычная ЦПТ с этой нормировкой неприменимы.

**Коши:** возможны большие скачки в обе стороны. Математическое ожидание не существует, конечной дисперсии нет. Симметрия плотности не означает нулевое математическое ожидание. Формулы `E[Sₖ] = kμ`, конечного разброса `σ√k` и обычная ЦПТ с этой нормировкой неприменимы. У остальных пяти законов задачи 3 среднее и дисперсия конечны, поэтому соответствующие формулы применимы.
